# FO3_repair
Auto repair mod for Fallout 3
Use build-online.yml in a new GitHub repository:
1. Create a new empty GitHub repo.
2. Add a new file named: .github/workflows/build.yml
3. Paste the full contents of build-online.yml into it and commit.
4. Open Actions -> Build Auto Duplicate Repair -> Run workflow.
5. When green, open the run and download artifact: AutoDuplicateRepair-FO3.
6. Extract it and copy its Data folder into your Fallout 3 game folder.
